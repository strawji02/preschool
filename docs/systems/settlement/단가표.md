# 신세계 월별 단가표

> 정산 시스템 상세 — **필요할 때만 연다.** 개요·산식은 `../settlement.md`.
> ⚠️ 섹션 번호는 코드 주석(`docs §21` 등)이 참조하므로 **바꾸지 않는다.**

## 21. 신세계 월별 단가표 (2026-08-14 구현)

신세계가 **매달 10일 전에** 보내는 품목 카탈로그다.

```
순번 카테고리 품목군 품목코드 품목명 단위 원산지 규격
     종전단가 결정단가 변동율 과면세 발주구분 협력사
```

26년 6월 7,798개 · 7월 7,818개 · 8월 7,828개.

### 왜 필요한가 — 원산지

§19에서 거래명세표의 **원산지 열을 비워 뒀다.** 우리 원천에 그 열이 없어서
품목명의 `국내산` 정도로 흉내 내면 틀린 원산지를 유치원에 주게 되기 때문이다.

단가표에 **원산지가 품목코드 단위로** 들어 있다. 이제 채운다.

```
26년 6월 국제유치원   품목 329행 중 324행 원산지 채움 (98.5%)
급식재료 시트         232행 중 228행
못 찾은 코드 2개      041258 무항생제 계란 · 199562 쉐프초이스 군만두
```

⚠️ **못 찾으면 빈칸으로 둔다.** 추정해 넣으면 §19에서 피하려던 그 문제가 그대로 온다.
못 찾은 품목은 7·8월 카탈로그에도 없다 — 단종되었거나 카탈로그 밖이다.

### 결정단가는 우리 원가다

26년 6월 실측에서 원천의 **납품단가와 523건 전부 일치**했다.
가맹점 단가(유치원 청구가)와는 0건 — 그건 우리가 붙인 판매가다.

원천이 이상한지 교차검증하는 데 쓸 수 있다 (아직 미구현).

### ⚠️ 파일에 연월이 없다

헤더 어디에도 월 표기가 없고 **파일명에만 `6월`** 이 있다. 사용자가 잘못 고르면
다른 달 단가가 조용히 들어간다 — 매달 5~10%가 바뀌므로 눈치채기 어렵다.

```
6월 변동 398개 (5.1%) · 7월 803개 (10.3%) · 8월 446개 (5.7%)
```

다행히 데이터 안에 근거가 있다 — **새 파일의 종전단가 = 직전 달 결정단가.**

```
6월→7월  7,798 / 7,798   100%    ← 맞게 고름
7월→8월  7,818 / 7,818   100%
6월→8월  6,927 / 7,798    88.8%  ← 한 달 건너뜀, 차단됨
```

문턱은 **97%**다. 정상이 딱 100%라 여유를 크게 둘 이유가 없고, 90%로 두면
오선택이 겨우 걸린다. 신세계가 몇 건을 소급 정정하는 정도는 통과한다.

### 품목코드는 6자리로 맞춘다

⚠️ 엑셀이 `017392`를 **숫자 17392로** 주는 일이 있다. 그대로 두면 원천의
`017392`와 안 붙어 **원산지가 통째로 빈다.** 양쪽 다 0채움해서 잡는다.

### 왜 파일이 아니라 테이블인가 (§20과 다르다)

```
원천     정산이 통째로 읽는다        → 파일 + 매번 파싱 (1~2ms)
단가표   품목코드로 단건 조회한다     → 테이블 (migration 061)
         "어느 달이 있나"도 알아야 한다
```

읽기가 0.24~0.41초라 매 요청마다 파싱하기엔 아깝다.
연 12개월 × 7,800행 = **9만 4천 행** — 작다.

⚠️ **조회는 필요한 코드만.** 한 달치를 통째로 읽으면 2.8초, 명세표가 쓰는
수백 개만 물으면 **0.6~0.7초**다.

⚠️ **월 목록은 DB 뷰가 집계한다** (`shinsegae_price_book_periods`).
앱에서 세면 9만 행을 통째로 읽게 된다.

### 저장은 그 달을 통째로 갈아끼운다

품목이 빠진 달을 다시 올렸을 때 옛 품목이 남으면 **그 달에 없던 원산지가
명세표에 찍힌다.** 먼저 지우고 넣는다.

### 화면 (9번 거래명세표 섹션)

정산월 옆이 아니라 **명세표 섹션**에 둔다 — 단가표는 정산 계산에 안 쓰이고
명세표의 원산지에만 쓰인다.

- 기본값은 정산월. 다른 달을 고르면 경고를 띄운다
- 그 달 단가표가 없으면 **"원산지 열이 빕니다"** 라고 미리 알린다
- 올리기는 같은 자리에서 — 고른 달로 저장된다

### 적재 실측 (26년 6~8월)

```
저장   7,798행 9.5초 · 7,818행 9.8초 · 7,828행 7.4초  (1,000행씩 나눠 넣음)
조회   550개 코드 → 741ms
```
