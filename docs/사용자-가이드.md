# 급식 정산 시스템 사용 가이드

> 퍼스트 컨설팅 내부 업무 시스템
> 주소: **https://firstconsulting.site/app**
> 최종 수정: 2026년 7월 31일 (v2)

---

## 이 시스템이 하는 일

매달 신세계·CJ에서 받은 엑셀 파일 하나만 올리면

- 영업자별로 얼마를 줘야 하는지 계산하고
- 홈택스에 그대로 올릴 수 있는 **계산서 파일**을 만들고
- 유치원 입금과 영업자 지급을 **추적**하고
- 그 달의 **손익 보고서**를 뽑아 줍니다.

엑셀을 손으로 만지던 일을 대신합니다. **원천 파일은 절대 수정하지 않습니다** —
올려도 원본은 그대로 남습니다.

①~⑤는 **급식 정산** 화면에서, ⑥은 **수금·지급**, ⑦은 **경영 보고서**에서 합니다.

## 4. ① 파일 올리기

**급식 정산** 화면 → `1. 원천 파일 업로드`

```
┌─────────────────────────────────────────┐
│                                         │
│  파일을 화면 아무 곳에나 끌어다 놓거나     │
│  클릭해서 선택하세요                      │
│                                         │
└─────────────────────────────────────────┘
              [ 분석 ]
```

**세 가지 방법 중 아무거나** 됩니다.

1. 엑셀 파일을 화면 위로 **끌어다 놓기** (화면 어디든 상관없습니다)
2. 점선 상자를 **클릭**해서 파일 선택
3. 파일을 복사한 뒤 화면에서 **Ctrl + V**

**통합 파일 1개**를 올려도 되고, **신세계·CJ 2개**로 나눠 올려도 됩니다.
어느 시트가 신세계이고 CJ인지는 시스템이 알아서 판별합니다. 시트 이름이
달라도 내용을 보고 찾습니다.

파일을 넣었으면 **[분석]** 버튼을 누릅니다. 몇 초 걸립니다.

## 5. ② 확인하고 고치기

분석이 끝나면 화면에 여러 섹션이 나옵니다. **위에서부터 순서대로** 보시면 됩니다.

### 「마감 전 해결할 항목」이 뜨면

빨간 상자로 이런 안내가 나올 수 있습니다.

| 안내 | 뜻 | 할 일 |
|---|---|---|
| 담당 영업자 미지정 | 새 유치원이 생겼습니다 | 목록에서 담당자를 고르세요 |
| 유치원 사업자 정보 없음 | 계산서를 만들 수 없습니다 | 사업자번호·대표자·주소 등을 입력 |
| 품목명 미지정 | 계산서에 쓸 품목명이 없습니다 | 품목명을 고르거나 입력 |

**그 자리에서 바로 고칠 수 있습니다.** 다른 화면으로 갈 필요 없습니다.
고치면 자동으로 다시 계산됩니다.

> 💡 한 번 입력하면 다음 달부터는 자동으로 기억합니다. 매달 다시 넣지 않아도 됩니다.

전부 해결되면 초록색으로 바뀝니다.

```
✓ 마감 전 확인 — 4개 항목 모두 통과
```

### 「3. 사업자공제 입력」

영업자에게서 빼야 할 금액이 있으면 여기에 넣습니다.
**[+ 공제 항목 추가]** → 항목 선택 → 금액 입력 → 비고(선택).

숫자를 넣는 즉시 아래 정산 금액이 바뀝니다. 저장 버튼은 없습니다.

### 「4. 영업자별 정산」

계산 결과입니다. 영업자마다 얼마를 받고 얼마를 주는지 나옵니다. 확인만 하세요.

### 「5. 사업소득 지급명세서」

한 사람이 여러 명의로 나눠서 신고해야 하면 **[분할 신고 설정]**을 누르고
이름과 금액을 넣습니다. 대부분은 건드릴 일이 없습니다.

⚠️ 나눈 금액의 합이 신고액과 **정확히 같아야** 마감이 됩니다.
다르면 빨간 안내가 뜨고, **[남은 금액 채우기]**를 누르면 자동으로 맞춰집니다.

## 6. ③ 확정하기

화면 맨 아래 **「8. 월 마감」**으로 갑니다.

```
8. 월 마감  [작성중]

     [ 확정 ]   [ 마감 ]
```

**먼저 [확정]을 누르세요.**

| | 확정 | 마감 |
|---|---|---|
| 보고서·계산서 | 나옵니다 | 나옵니다 |
| 금액 수정 | **됩니다** | 안 됩니다 |

**확정은 되돌릴 수 있으니 부담 없이 누르셔도 됩니다.** 세무사 확인이 끝나기 전까지는
확정 상태로 두고, 필요하면 몇 번이든 고쳐서 다시 저장하면 됩니다.
(다시 저장할 때는 이유를 한 줄 적어야 합니다 — 이력에 남습니다.)

## 7. ④ 서류 받기

서류는 **두 곳에서** 받을 수 있습니다.

| 어디서 | 언제 |
|---|---|
| **급식 정산** 화면 | 파일을 올려 분석한 직후 |
| **경영 보고서** 화면 | 확정·마감한 뒤 **언제든** |

**경영 보고서 쪽을 권합니다.** 원천 파일을 다시 올릴 필요가 없고, 확정한 그 시점의
값으로 만들어 주기 때문에 **몇 번을 받아도 똑같은 파일**이 나옵니다.

### 홈택스 계산서 — 「6. 홈택스 계산서 일괄발행」

```
  [ 세금계산서 47장 ]   [ 계산서 41장 ]
```

**두 개를 각각 눌러 받으세요.** 과세와 면세는 홈택스 양식이 달라서
파일이 따로 나옵니다.

받은 파일은 **손대지 말고 그대로** 홈택스 일괄발행에 올리시면 됩니다.
작성일자는 그 달 말일로 자동 입력됩니다.

### 정산 내역서 — 「7. 내역서 다운로드」

```
정산 기간 [2026-06]    [ 엑셀 다운로드 ]
```

엑셀 파일 하나에 시트 3개가 들어 있습니다.

- **집계표_정산용** — 기존에 쓰시던 것과 같은 형식
- **사업자공제 상세** — 어떤 공제를 얼마 넣었는지
- **사업소득 신고내역** — 세무사 제출용 지급명세서

> 주민등록번호는 시스템에 저장하지 않습니다. 지급명세서의 주민번호 칸은
> **빈칸**으로 나오니 세무사께 보내기 전에 채워 넣으세요.

- ✅ 그 달의 숫자가 **완전히 고정**됩니다
- ✅ 나중에 담당 영업자를 바꿔도 **지난달 서류는 그대로**입니다
- 🔒 공제·분할 입력이 **잠깁니다**
- 📄 계산서·내역서는 **계속 받을 수 있습니다**

마감된 화면은 이렇게 보입니다.

```
  공제·분할신고 입력이 잠겼습니다.
  고쳐야 하면 관리자에게 마감 해제를 요청하세요.
```

## 9. ⑥ 수금·지급 기록하기

**수금·지급** 탭으로 갑니다. **마감된 달만** 나옵니다.

```
현금 현황
청구 합계        수금      미수금        미지급(영업자)
```

### 유치원 입금이 들어오면

`유치원별 입금` 목록에서 해당 유치원의 **[입금 기록]**을 누릅니다.

- **입금일자만 넣으면 청구액 전액으로 기록됩니다.** 대부분 이 경우입니다.
- 일부만 들어왔으면 금액을 고쳐 주세요.

### 영업자에게 지급할 때

돈이 다 안 들어왔는데 먼저 나가는 일을 막기 위한 장치입니다.

> 💡 **수금·지급은 마감한 뒤에도 계속 입력합니다.** 현금은 마감 뒤에 들어오니까요.
> 여기에 뭘 입력해도 청구액·지급액 자체는 달라지지 않습니다.

## 11. 자주 겪는 상황

### 로그인이 안 됩니다

`접근 권한이 없는 계정입니다`가 뜨면 **다른 구글 계정으로 로그인된 것**입니다.
크롬 우측 상단 프로필 → 계정을 `ilsinkim0616@gmail.com`으로 바꾸고 다시 시도하세요.

### 파일을 올렸는데 "엑셀 파일만 올릴 수 있습니다"가 뜹니다

`.xlsx` · `.xls` · `.xlsm`만 됩니다. PDF나 CSV는 안 됩니다.

### 「담당 영업자가 지정되지 않은 사업장」이 나옵니다

**새 유치원이 생긴 것입니다.** 정상적인 상황이니 목록에서 담당 영업자를 고르면 됩니다.
한 번 고르면 다음 달부터는 자동입니다.

### 계산서 장수가 지난달과 다릅니다

유치원이 늘거나 줄었거나, 품목이 바뀐 것입니다.
계산서는 **유치원 × 품목 × 과세구분** 단위로 나옵니다.

### 마감 버튼이 눌리지 않습니다

위쪽 **「마감 전 해결할 항목」**에 남은 게 있습니다.
전부 초록색이 되어야 눌립니다.

### 화면을 새로 열었더니 다운로드 버튼이 안 보입니다

**급식 정산** 화면은 파일을 올려 분석해야 5·6·7번 섹션이 나타납니다.
이미 확정한 달이라면 **경영 보고서**로 가서 `산출물 다시 받기`를 쓰세요.
파일을 다시 올릴 필요가 없습니다.

### 실수로 마감했습니다

관리자에게 연락하세요. 해제할 수 있습니다. 데이터는 사라지지 않습니다.
